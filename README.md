8-Bit ALU Using Verilog

Overview

This project implements an 8-bit Arithmetic Logic Unit (ALU) using Verilog HDL. The ALU performs arithmetic, logical, and shift operations based on a 3-bit select signal.

Operations

- Addition
- Subtraction
- AND
- OR
- XOR
- NOT
- Left Shift
- Right Shift

Tools Used

- Verilog HDL
- Vivado 2025.2

Verification

The design was verified using a custom testbench and behavioral simulation in Vivado. Waveform results are included in this repository.

Files

- "8bit_ALU.v" - ALU design
- "alu_tb.v" - Testbench
- "waveform.png" - Simulation output
